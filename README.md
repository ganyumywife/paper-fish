# 纸想摸鱼 · 桌面便签本

按 [项目需求](./桌面便签本项目需求说明.md) 开发的 Windows 桌面便签应用。当前版本 v0.13.1，完整使用方法见 [使用说明](./使用说明.md)，已实现与待完善项目见 [验收清单](./项目验收清单.md)。性能优化及测量见 [性能评估](./性能与内存评估.md)。

## 直接使用

源码仓库不包含 exe 和运行时。如作者已在仓库 Releases 发布 Windows x64 便携包，可下载、完整解压后运行 PaperDesk.exe。开发者可按下方步骤从源码运行或自行打包。

开发目录也可以双击 `启动便签.cmd`。

## 当前功能

- 透明桌面便签本、独立钉贴、置顶、双下角及 Ctrl+滚轮整体缩放、锁定、托盘和显示快捷键。
- 自适应侧边工具、悬停展开、悬浮球收放动画、可移动球及贴边吸附。
- 独立图片录入侧窗，固定追加目标、隐藏保留草稿。
- 长内容拆页预览、逐页校对、分开/合并，确认后按顺序录入。
- 显示/隐藏、新建和查找的快捷键配置，冲突校验、停用和重启恢复。
- 显示器变化后的纸面、悬浮球、道具及侧窗恢复；可开启前台全屏避让，保留手动显隐优先级。
- 多页编辑、自动保存、纸色字体与整页文字样式、可点击待办与选区加粗、字号、字色。
- 圆角/直角、圆形、心形和不规则撕边纸，搭配空白/横线/方格纹理，安全文字区和透明边缘穿透。
- 五种纸张均可从纸面上缘直接拖动，心形的两个上圆弧可分别移动；无顶部底板和连接装饰，顶部操作为半隐藏按钮。
- 显示比例独立保存，纸张与文字同步缩放且换行容量不变；百分比重置、Shift 调整纸面容量，正文滚动条半透明。
- 可保存新页默认外观，纸团一键聚拢。
- 左右上角揭纸、短拖回弹、Esc 取消，带原文字的纸面连续揉团、展开和还原。
- 桌面纸团落地弹跳、相互碰撞和堆积、点击预览、拖回本子、垃圾桶投入动画与回收站。
- 木质弹弓、真实纸团装填、长射程拉伸、统一物理瞄准、旋转与尾迹；开口废纸篓支持桶口回收、侧撞反弹、晃动、击倒及点击扶正。
- 常用尺寸与纸色预设、创建及撕下时间、默认关闭的交互音效与音量。
- 全局文字搜索、按状态筛选、备份导出与合并导入（不含 API Key）。
- 图片选择、拖入、粘贴、旋转、框选裁剪与原图恢复。
- 自定义兼容 Chat Completions 的视觉 API，密钥系统加密、连接测试、识别校对与录入。

## 开发

需要 Node.js 22 或更新版本。

```powershell
npm install
# 如果安装环境禁用了依赖脚本：
node node_modules/electron/install.js
npm start
```

```powershell
npm test
npm run check
npm run test:desktop
npm run build:portable
node tests/portable.e2e.cjs
```

桌面测试使用独立临时配置，不修改用户便签。中间帧截图与测试数据在 `test-results/`。

## 数据与隐私

用户数据通常位于 `%APPDATA%/paper-desk`：`notes.json` 保存内容及布局，`notes.json.bak` 保存上次写入前的内容，`api-key.enc` 使用系统加密保存密钥。

图片仅在主动识别或测试接口时发给所配置的服务。备份只包含页面；导入时合并生成新页面，不覆盖已有记录。无 API Key 时其他功能可离线使用。

## 当前边界

纸张动画为二维纹理网格模拟，尚未达到完整纸张力学仿真。后续扩展包括多图和多协议 AI、云同步、多便签本、自由手写及其他平台。当前提供未签名的便携包，尚无签名安装包或自动更新。真实外部模型和异构多屏还需要实机验收。

技术参考：[BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window)、[safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage)。

置顶、收起、隐藏和齿轮设置位于纸张上方，淡显按钮在悬停或聚焦时清晰显示；其余工具从侧边“···”打开。拖动纸面上缘的点状手柄或异形纸的非正文区域可移动便签，上方透明空白穿透鼠标。
